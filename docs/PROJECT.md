## 复现

沿用Python、uv、本地.venv及uv.lock。默认validation/0.4.0和outputs/0.4.0。

- `uv run python -B scripts/full.py run`
- `uv run python -B scripts/full.py finish`
- `uv run python -B scripts/full.py export`
- `uv run python -B validation/0.4.0/evaluate_stage.py`
- `uv run python -B -m unittest discover -s tests`

finish保留0.1.0固定参考、0.2.0和0.3.0首答及显式更正，新增参考冲突不覆盖首答。完整历史统计见原阶段报告；软件版本、规则编号不是质量证据。
