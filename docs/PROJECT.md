# 项目总览

## 目标与范围

从任职资格批复的标题中提取姓名，处理约 5.2 万条记录，在原表增加“提取姓名”和“姓名字数”两列。准确率要求为 99.8% 以上，目标 100%，交付前必须人工检查。

完整要求以 [项目要求](../项目要求.md) 为准，本文不重复全部验收条款。
