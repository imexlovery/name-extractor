## 使用与文档入口

现有Python/uv与本地.venv、uv.lock流程不变。

- `uv run python scripts/full.py run`：全量规则、独立检查、版本差异和历史回归，不调用模型。
- `uv run python scripts/full.py reviews-extra`：保留历史范围并追加缺失盲批次，缓存支持断点。
- `uv run python scripts/full.py finish`：合并有效A/B参考、保留分歧，生成内部审计/Excel输入，不调用模型。
- `uv run python -m unittest discover -s tests -v`：运行必要契约、故障和输出保留测试。
