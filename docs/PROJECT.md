## 复现

沿用Python、uv、本地.venv及uv.lock，未新增依赖。默认validation/0.5.0和outputs/0.5.0。

- `uv run python -B scripts/full.py run`
- `uv run python -B scripts/full.py finish`
- `uv run python -B scripts/full.py export`
- `uv run python -B validation/0.5.0/evaluate_stage.py`
- `uv run python -B -m unittest discover -s tests`

finish复用v1、v2、0.3.0和0.4.0参考及显式更正，不重复调用已有判断。软件版本、规则编号和合成通过率不是真实准确率证据。
