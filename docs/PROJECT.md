## 复现

沿用Python、uv、本地.venv及uv.lock，无新增依赖。默认validation/0.6.0，导出outputs/0.6.0。

```sh
uv run python -B scripts/full.py run
uv run python -B scripts/full.py export
uv run python -B validation/0.6.0/evaluate_stage.py
uv run python -B -m unittest discover -s tests
```

run保存源码和实际资源，同时比较上一轮及r56；finish/export复用旧参考，但只用脚本写生产单元格。prepare.py整理人工原值和检查入口，原随机名单不重抽。原始数据、人工表和0.5.1冻结材料不覆盖。
