## 使用与文档入口

沿用 Python / uv、项目本地 `.venv` 和 `uv.lock`。

- `uv run python scripts/full.py run`：全量规则、独立检查、版本差异和历史回归，不调用模型；目前仍依赖 `.local/` 实验数据。
- `uv run python scripts/full.py reviews-extra`：追加缺失盲批次，不直接执行模型调用。
- `uv run python scripts/full.py finish`：当前生成历史混合输出，尚未改为纯脚本生产出口，详见 [PLAN](PLAN.md)。
- `uv run python -m unittest discover -s tests -v`：现有业务、回归、参考处理与 Excel 保留测试。

`.local/pilot-20261010/`、`.local/full-20261011/` 仍保留详细历史实验、首次标签和渲染证据，但被 Git 忽略；V1 快照不等于保存了整个 `.local/`。历史报告和混合疑点清单保留作阶段记录，当前下一步以 [PLAN](PLAN.md)为准。
