# 系统结构

## 当前实现

Python 3.13、uv和项目本地.venv沿用现有依赖流程。openpyxl用于读取标题；Excel写回使用标准库ZIP/XML。Word及小型Excel投影渲染使用捆绑运行时，不新增产品依赖。

| 模块 | 职责 |
| --- | --- |
| `scripts/extract.py` | r29标题规则，输出原文姓名片段、状态、规则、疑点；机构前后联合判断，无法确定保留未决 |
| `scripts/institution_anchors_r29.json` | 4,984机构片段，由有效A/B一致参考和原标题推导；加82基础锚点，实际5,066。不是姓名表或行号例外 |
| `scripts/validate.py` | 不导入提取器；独立片段、顺序、展示、字数、状态及结构风险检查 |
| `scripts/pilot.py` | 原实验、标题去重/行映射与持久化工具、历版匹配集合回归；旧证据保留不重写 |
| `scripts/full.py` | 全量运行、版本差异、动态盲队列、有效缓存与参考更正、冻结样本评价、审计和导出输入 |
| `scripts/excel_output.py` | 保留原包内容仅追加N/O；独立重读核对原值/类型/格式/结构及新增结果 |
| `tests/` | 14项业务、静默错误、回归/故障、参考处理与Excel保留验证 |

## 数据与流程

Sheet1标题位于A列，实际数据行2—52,147，共52,146记录。完全相同标题去重为46,760，内部每标题保存全部原行号，最终逐行写回。原max_row为1,048,576、XML行107,328（含格式行），不充当业务记录数。

原标题 → r29候选和全量独立检查 → 结构风险/未决/空姓名/冲突及普通分层抽样 → A/B盲判断 → 保留首次答案与必要更正 → 共同规则修订/全量回归 → 未用样本冻结后揭示 → 有效参考合并 → OOXML追加 → 原数据保留验证及渲染检查。

提取只接收标题，不向模型提供其他字段。正文只用于源/副本机械比较。姓名包含同一人的双语表达，原样保留大小写、空格和标点；不同人以全角分号连接。字数独立计算汉字（含扩展）与ASCII字母，不计标点和连接词。

机构锚点从明示姓名前或后、具有机构结尾的原文片段推导，泛银行词不作为可靠起点。机构尾部存在部门/职务时不得抢先当姓名；弱地区锚点不得覆盖完整机构词。和/及/与、长连续汉字、多个机构职位片段需要语义复核，不能用长度或姓氏表猜切。

## AI与缓存边界

A/B为gpt-6.1-sol/max的独立上下文，只有标题/标识/口径；每批约40，最多3子任务并发，无额外付费API。只精确标题可复用自己的有效缓存。全部历史队列范围保留，断点记录完成/缺失。首次答案不覆盖；更正保存before/after/理由，来源失败或语义分歧不得按多数票关闭。

候选姓名必须为连续原文且顺序对应；存在片段或硬检查通过不能证明语义正确。回归覆盖历版曾匹配有效参考的样本集合，比较姓名列表、展示值、字数、状态、硬失败；报告相邻版本变化、确定差异与保守状态退化。

普通样本种子20261012，逐层5%向上取整，复用冻结原清单并补足，不每轮重抽增加成本。五组冻结样本先排除已诊断/已复核标题，未揭示样本排除于机构学习；揭示后转回归。后两组仅覆盖尚未使用的普通类别，不能宣称仍有八类复杂结构的独立覆盖。

## 输出状态

| 状态 | 提取姓名 | 姓名字数 |
| --- | --- | --- |
| 可用姓名结果 | 原文姓名表达，多人全角分号 | 整数 |
| A/B复核确认无姓名 | 空 | 0 |
| 缺失/无效/分歧/未决 | 空 | 空 |

风险和疑点保存内部审计及单独CSV，Excel不增加其他字段或结果工作表。全部空姓名与未决进入复核；非目标低风险标题保留规则结果，不能声称全量都经AI逐标题标注。

OOXML修改保留原A—M单元格、行属性、其他ZIP成员与列格式；仅追加N/O数据和表头，扩展维度/筛选至O并设置新增列宽。独立重读验证52,146记录、677,898原字段位置、677,911原单元格XML、107,328XML行、16其他成员及104,294新增单元格。正文不参与提取。显示检查仅对最终新增列作小型投影，未做桌面Excel逐行人工检查。
