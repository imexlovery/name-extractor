# 当前结构

generic-v0.1 使用 Python 和 uv，沿用 openpyxl 与原有 OOXML 导出器。提取器只依赖标准库，不读取外部词库或精确标题例外。

| 文件 | 职责 |
| --- | --- |
| `extract.py` | 标题通用规则、候选与确定/无姓名/未决状态、姓名字数 |
| `validate.py` | 独立检查姓名在原标题中的顺序、状态、展示、字数和结构风险 |
| `source.xlsx` | 原始 52,146 条记录及 13 个字段，保持原文件内容 |
| `reference_v3.jsonl` | 固定全量回归标题与参考，保留原始行号、输入标识及信息冲突标记 |
| `evaluate.py` | 标题去重提取、逐原始行比较、差异分析、可选未见数据比较和 Excel 导出 |
| `excel_output.py` | 沿用原实现追加 N/O；独立验证原表字段、包结构和格式保留 |
| `tests/` | 通用结构、人数、参考与生产隔离、JSONL 行读取及原表保留测试 |
| `docs/` | 项目要求、原 Word 范本、历史规则 Word、现状、决策和小型基线指标 |

快评：固定参考标题 → `extract()` → 独立检查 → 与参考比较 → 汇总与错误记录。提取相同标题只执行一次；分母按 52,146 原始行加权。不同原始行的参考各自比较，不强行合并。

提取器仅保留地名及银行业/保险业/金融机构三个类型锚点。监管机关按主体构词和文书结构识别；没有具体银行、保险公司或按精确标题保存的姓名/弃权表。类型边界未知时保留未决，不以姓名字数猜陌生机构起点。显式单人人数可以解除长姓名歧义；四字姓名仍按通用规则处理并标记人数风险。

导出：先核对原 Excel 的标题和行号，再由脚本结果生成 `row/name/length`，调用原 OOXML 导出器。正常姓名按顺序全角分号连接；无姓名空/0；未决空/空。参考和正文均不参与生产填值。输出格式失败中止导出。`source.xlsx` 不被覆盖。

完整旧验收工具和数据只在 r65 冻结分支或历史归档中。新入口不导入 `full.py`、`acceptance.py`，不依赖 `validation/v1/script-r29.jsonl` 或历史阶段标签。原表格式保留是项目要求，因此保留现有 `excel_output.py` 作为额外的必要组件。
