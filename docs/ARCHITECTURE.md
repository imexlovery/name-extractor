# 系统结构

## 当前实现

Python 3.13、uv 和项目本地 `.venv` 沿用现有依赖流程。openpyxl 读取标题，Excel 写回使用标准库 ZIP/XML。0.1.0 / r29 已冻结；当前规则为 0.2.0 / r38，生产出口与 AI 验证已分离。

| 模块 | 职责 |
| --- | --- |
| `scripts/extract.py` | r38 标题规则，输出姓名片段、状态、规则和疑点；不读取 AI 答案 |
| `scripts/institution_anchors_r36.json` | 当前运行必需的 5,243 个机构片段，加代码中 82 个基础锚点，实际 5,325 |
| `scripts/validate.py` | 不导入提取器，独立检查片段、顺序、展示、字数、状态及结构风险 |
| `scripts/pilot.py` | 标题去重、原行映射、实验持久化和历史匹配集合回归 |
| `scripts/full.py` | 全量运行、版本差异、盲队列、参考缓存及更正、冻结样本评价；`finish()` 只生成脚本逐行输入和参考比较；`export` 沿用原导出器 |
| `scripts/excel_output.py` | 在原 OOXML 追加 N/O 两列，独立核对原值、类型、格式、结构及新增结果 |
| `validation/v1/` | Git 保存的脚本全量快照、AI 共识与排除项、参考更正、机构来源、冻结样本和统计 |
| `tests/` | 17 项业务、静默错误、历史回归、参考处理与 Excel 保留测试 |

## 数据与现有流程

Sheet1 标题位于 A 列，数据行 2—52,147，共 52,146 条记录、13 个原字段。完全相同标题去重为 46,760 个，内部保存全部原行号，最终逐行映射。原 max_row 为 1,048,576、XML 行 107,328（含格式行），不作为业务记录数。

提取线：原标题 → `extract()` → 全量脚本结果及独立检查 → `validation/v2/script-r38.jsonl`。当前168标题/177原行未决；r29的812标题/871行只作改善基线。

AI 验证线：原标题与口径 → A/B 独立上下文判断 → 首答及显式更正 → 共识参考或排除项。A/B 为同一 gpt-6.1-sol/max，只接收标题，不看脚本答案或彼此答案。

当前生产出口：脚本结果 → `production_records()` → `excel-records.jsonl` → 原OOXML追加；姓名/字数取脚本值，无姓名空/0，未决空/空。AI旁路经`comparison_state()`写审计：匹配、确定差异、无姓名争议、脚本未决及参考缺失/无效/单渠道/分歧。脚本输出合同失败中止导出，不用AI替换。

0.1.0混合实验出口保留为历史，20标题/22行未决不能代表当前脚本能力。0.2.0新增独立A/B为gpt-6.1-sol/medium，只读标题和口径；0.1.0既有标签模型配置属于历史。

正文仅参与原表保留比较，不参与提取或标注。不同人全角分号连接；同人的双语表达保留原文大小写、空格和标点。字数计算汉字（含扩展）与 ASCII 字母，不计标点和连接词。

## 机构锚点及历史资源

Institution Anchors 是机构边界词库，不是姓名表。锚点从有效 A/B 共识支持的原标题中，明示姓名前后具有机构结尾的片段推导；泛银行词和弱地区词不能可靠猜切，无法确定则留未决。数据机构词仍不能证明对新机构的泛化。

当前仅 `institution_anchors_r36.json` 被提取器显式读取；r29 资源已移出 `scripts/`，可从 `validation/archive/0.2.0-rounds.zip` 或 0.1.0 提交 `5ed9094` 恢复。机构括注与标题同时屏蔽但保留原偏移，掩码只在加载时计算一次。r18、r19、r22、r28 资源是早期规则 / 冻结实验的历史词库，已从 `scripts/` 移除；可从 0.1.0 提交 `5ed9094` 或现存 `.local/full-20261011/` 恢复。它们不需要参与当前运行，但重跑对应历史源码时仍需使用对应资源。

`full.py run` 会保存当前源码及实际读取的词库。逐轮历史归档不参与当前运行；r37 盲测冻结源码及其 r36 资源仍保留在 `validation/v2/`。

## AI 参考与统计边界

`validation/v1/ai-references.jsonl` 保存 23,387 个有效共识参考，与脚本快照分开；`ai-reference-exclusions.jsonl` 保存 35 个单渠道和 20 个分歧 / 未决标题，不能作为确定答案。5 条更正保留 before/after、理由和来源；首次原始标签仍在 `.local/`。

比较时同时检查姓名列表、展示值、字数与状态。r38 在固定0.1.0共识范围内完全匹配 23,235、未决 152、确定差异 0；其余标题分别属于单渠道、参考分歧或未覆盖，不能计为正确。回归比较已经用于调规则的参考集；未见样本只能来自未参与诊断或锚点学习的数据。

现有缓存按精确标题 / 原行标识复用，来源失败、缺失、语义分歧不按多数票关闭。五组冻结样本各 400，后两组仅普通结构。0.1.0普通分层5%清单继续作为已有覆盖。本轮按用户新授权先测21标题，再复核101标题；其中100个普通未见样本以种子2026101137分成72个关于、28个核准结构。冻结r37后揭示，随后转回归；没有新复杂未见样本。

## Excel 与证据

现有导出器接受逐原行的 `row/name/length`；姓名正常填值，无姓名空 / 0，未决空 / 空。不新增结果工作表或其他 Excel 字段，风险另存审计和 CSV。

OOXML 追加保留原 A—M 单元格、行属性及其他 ZIP 成员，仅扩展维度 / 筛选至 O 并设置新增列宽。历史混合副本已逐项验证 52,146 记录、677,898 原字段位置、原值 / 类型 / 格式和结构，新增两列与当时混合输入一致；这种机械验证不能证明纯脚本提取正确。

`.local/` 被 Git 忽略，保存更详细的历史源码、全量结果、首次标签、批次、审计和渲染；`validation/v1/` 是不可覆盖的Git基线。`run()`从它读取标题映射，`labels()`默认读取0.1.0有效参考及排除项，再读取0.2.0新标签；新旧语义冲突保留未决，不以后答覆盖首答。0.2.0 首答、ok 到 names 的机械字段规范化前后、当前机构来源、全量及 r37 冻结快照保留在 `validation/v2/`；逐轮源码、旧资源、变化及比较集中到 Git 保存的 `validation/archive/0.2.0-rounds.zip`。大体量中间全量及 Word 历史保存在未随 Git 保存的 `.local/archive/0.2.0-local-history.zip`，归档保留原相对路径。0.1.0和0.2.0快照都不是整个实验目录的备份。真实准确率未评估、人工检查未执行，AI 共识和格式检查不能替代验收证据。
