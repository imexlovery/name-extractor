# 0.3.0 下一步计划

更新日期：2026-10-11。当前已完成的阶段版本为 **0.2.0 / r38**；0.3.0 尚未实施。本次统一版本命名和编写计划，不计作新的提取规则修改轮次。

## 目标与执行边界

0.3.0 优先解决已确定输出中的错误风险，再收敛有通用标题依据的未决，最后补充复杂结构验证。生产 Excel 继续完全来自脚本；AI 只提供验证参考，不回填姓名。只读标题，不借正文补充答案。

沿用现有 Python/uv、提取器、全量入口、参考缓存及 OOXML 导出器。每轮修改同步 Word 方案并执行全量回归；不做大规模重构，不添加姓名词库、行号特判或机械长度猜切，不为未决归零放宽判断。新增 AI 判断仅用于必要的新样本、争议及同类扩查，不重新启动数万标题的 A/B 标注。继续使用既定 gpt-6.1-sol/medium 和当前 Codex 额度，不增加付费 API；如确需数千以上新增标注，先说明必要性、规模和预计额度再确认。

### 1 保存 0.2.0 基线并先处理 5 个确定输出疑点

本次整理提交保存当前代码、实际机构资源、Word、参考首答及更正、全量结果、Excel 和报告，作为 0.2.0 / r38 Git 基线；实施 0.3.0 时从该提交比较。`validation/v1/`、当前 `validation/v2/` 和原附件保留；逐轮历史集中到 `validation/archive/0.2.0-rounds.zip`，大体量本地历史集中到 `.local/archive/0.2.0-local-history.zip`。本地归档未随 Git 保存。0.3.0 的提取改进仍未实施。

复用已有判断、候选和原标题依据；只有缺失或矛盾仍影响裁决时才补充定向独立复核。每项记录原标题依据、裁决和同类标题扩查结果。确认错误用通用规则修复；标题信息不足则通过通用规则保留未决；依据充分才能保留确定输出并关闭疑点。不按行号修改结果，不以多数票或新模型共识自动关闭历史争议。

完成标准：5 项均有明确处理结论；不能判断的项继续披露为未决，不能当作已验证正确。新增或修复的同类规则必须经过全量回归。

### 2 分组收敛 168 个未决

按当前疑点原因处理，优先寻找可以推广的机构、职务、后缀和字符结构依据：

| 当前主要原因 | 标题数 | 处理方向 |
| --- | ---: | --- |
| 机构起点未确定 | 32 | 复用有来源的机构片段，核对机构与姓名的边界 |
| 缺少任职资格结构 | 25 | 区分机构事项、标题未明示姓名和仍有被批复人结构的标题 |
| 机构及分支间可能含姓名 | 21 | 同时检查机构之间、岗位前后片段，避免漏提或误判无姓名 |
| 长连续汉字 | 50 | 检查完整长姓名与连写多人；没有结构依据继续未决 |
| 和 / 及 / 与关系 | 24 | 区分姓名内部字符、并列人物与机构文字，避免一律拆分 |
| 其他边界、重复结构、称谓与异常字符 | 16 | 处理已观察到的共同结构，不用个案补丁凑归零 |

优先复用 152 个固定参考，另外 16 个按已有争议依据处理。36 个无姓名参考尤其要区分“标题确无姓名”和“脚本漏提”，不能将所有空结果写为 0。35 个历史单渠道参考仍按单渠道披露。

每轮先说明共同结构和改动依据，再同步 Word、修改最小必要代码、全量运行并比较。相邻版本记录未决转姓名、未决转无姓名、确定转未决、确定输出变化、修复差异及新增差异；检查姓名列表、展示、字数和状态。复用现有测试，只为实际观察到的新错误添加必要回归样例。

完成标准：可形成通用规则的组已处理，已发现的确定错误已修复，固定参考没有剩余新增确定差异；历史匹配转未决也必须列明原因，不能静默忽略。未决允许保留，并记录缺少什么标题依据。不设必须降到某个数字或归零的目标。

### 3 独立筛查并补充复杂结构验证

先盘点尚未参与诊断、规则调试或机构学习的标题。独立检查标题原始结构，包括重复任职片段、多个机构或岗位、中外文及异常字符、连接词和缺失后缀；不要只沿用提取器已有风险标签来断言剩余标题都是普通结构。

优先选择真正未用的复杂真实标题，留存选择依据、结构分布、原标题和原行映射。选择过程中若某标题已被用于分析或改规则，就转入诊断 / 回归集，另选未揭示样本。机构资源学习同样排除未揭示的验证样本。

规则及实际机构资源冻结后，再以两个独立上下文进行小规模盲判断，只提供标题和口径，不提供脚本答案、彼此答案或正文。按实际找到的结构和样本量决定规模，不预设必须凑足数量；参考分歧与未决另报。

如原数据没有适当的复杂未用标题，报告该限制；可以明确标记构造样例作压力测试，但不将其计为真实标题泛化或全量准确率证据。需要从原数据之外取得新标题时，先说明来源和范围，再确定是否扩展任务。

完成标准：报告有真实新样本的结构覆盖及逐项比较结果，或明确披露真实复杂未见证据仍缺失。盲测发现问题后修复并重跑回归，已揭示样本不能再称第二轮未见测试。原有 100 个普通未见样本已转回归，不重复调用或声称新的独立证明。

沿用现有入口做最小调整，复用 0.1.0 固定参考、0.2.0 新增参考及排除项，并以 r38 作本轮变化基线。新规则轮次从 r39 延续；实现完成后将项目版本改为 0.3.0。0.3.0 结果和新增判断另存 `validation/0.3.0/`，Excel 副本另存 `outputs/0.3.0/`，不覆盖 0.2.0 材料。

最终执行全量提取、固定参考比较及必要测试，沿用原 OOXML 导出器保留 52,146 行、13 个原字段和格式，仅追加提取姓名、姓名字数；无姓名空 / 0，未决空 / 空，不新增工作表。检查原字段保留、输出与脚本逐行一致及代表行显示，并维护 Word 和相关项目文档。

报告至少列出：最新未决标题 / 原行及分类、5 项原疑点的处理结论、确定错误修复与新增情况、固定参考匹配 / 差异 / 未决、历史回归、新样本来源与结构覆盖、实际新增 AI 判断数量、真实准确率及人工检查状态。依据不足的成果继续标为待复核。

## 阶段完成与最终验收

上述四步完成、已发现确定错误归零、无未处理的新增确定参考差异，且剩余歧义和验证缺口清楚披露后，可以结束 0.3.0 阶段。不能为降低未决数继续增加没有依据的规则，也不将阶段完成写成原邮件最终验收通过。

23,235 个已有匹配样本已参与调试，只证明工程回归；A/B 是同一模型的独立上下文，仍可能共同出错。真实准确率目前未评估，人工检查未执行。若验收将未决行计错，当前 177 行约占 0.34%，即使其他行全部正确也只有约 99.66%；52,146 行要超过 99.8%，错误总数最多 104 行。这个算术边界不证明其他行正确，也不替代独立准确率证据。

原邮件的准确率、人工检查和最终 HR 检查条件仍须另行满足；没有相应证据时继续披露未完成。未经用户授权不外发。
