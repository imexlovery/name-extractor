2. 对52,146条完成独立AI审查。第一轮严禁接收脚本结果或旧参考。仅完整五个输入字段相同可缓存复用，建立逐行验收记录。先试审200条不同结构记录，核对提示词、输出、token与耗时；分批保存进度、失败、补审及成本统计。使用本会话 `gpt-6-luna/xhigh` 子智能体，不新增付费API；Fast工具不可控时记未验证。
3. 每条输出原始行ID、有序姓名数组、标题原文证据/位置、正文支持证据、确认有姓名/确认无姓名/冲突/无法裁决状态、依据、模型与提示词版本。全量逐项比较姓名、人数、拆分、空值、状态；一致且证据充分暂列通过。第二轮重新独立看原材料，避免首答/脚本暗示，必要时第三次裁决。优先覆盖79未决、历史多人人数风险、外文逗号/连写/复杂机构、不同AI结论及一致但有风险记录。裁决必须有证据，无法裁决不计正确。
4. 人工固定100条，上限100：60条按年份、地区、结构分层随机，40条风险样本覆盖多人、AI分歧、无姓名及历史问题。先记录原标题/必要正文的独立判断再看AI与脚本。记录正确、错误、无法判断及理由；旧人工材料只交叉比较，AI不能冒充人工抽检。
5. 参考集冻结后，只修复具体验收错误支持的规则，不为提高AI一致率盲加分支。不得手改最终单元格或AI回填。每次规则修正后全量52,146行回归；参考集被证实错误时保留裁决证据及旧版本。确认无姓名可正确留空，未查清空值继续列未决。
