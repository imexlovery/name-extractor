# generic-v0.1 通用规则方案

本方案对应 `extract.py` 当前实验，不使用具体机构词库、姓名表、行号或精确标题例外。历史规则 Word 单独标为 r65；新实验没有通过最终验收。

1. 只消费原标题。剥离完整的监管文书抬头、“关于”、核准等许可动词，定位任职资格或明确岗位。完整规范事项与机构业务事项可以判为无姓名；残缺标题保留未决。
2. 括号外建立等长掩码，保留原字符位置。中文和外文别名、括号与中点按原标题保留，不从正文补名。明确的机构标题、冒号或“岗位名单”结构可递归提取名单。
3. 根据机构类型后缀、地名和岗位确定姓名在机构前或机构后的边界。类型与完整岗位需要共同成立；未知机构起点不按常见姓名长度猜切。地名锚点允许使用，其内容不从当前评测答案扩充。
4. 明示顿号、分号、完整人员岗位子句可以形成多人名单；“和/及/与”必须结合完整岗位、明示人数或“分别”等证据。连续汉字不按二字、三字姓名猜拆。岗位结束后剩余人员片段，以及机构两侧都有完整人员解释时，保留冲突候选和未决。
5. 单人、两人等明确人数与最终姓名片段数核对；“等 N 人”只输出前面明示姓名，不补齐省略名单。长姓名和连写多人无法区分时保留原候选；四字姓名使用通用规则，同时由独立检查记录人数边界风险。
6. 输出 `names/no_name/uncertain`、原文姓名列表、触发规则和说明。不同人以全角分号展示；同人双语表达不拆分。只计汉字（含扩展字）与 ASCII 字母，不计空格、标点和连接分隔符。
7. 独立检查原文存在、顺序、展示、字数和状态。Excel 仅追加“提取姓名”“姓名字数”：姓名正常填值，无姓名空/0，未决空/空。参考答案只能评测，不能参与填值。
8. 每轮用固定 v3 比较全部原始行，查看确定分歧、未决和风险；只修改有具体证据支持的通用结构。未参与优化的新标题另作独立检验。回归一致率、测试通过、格式保留与真实准确率分别报告。
