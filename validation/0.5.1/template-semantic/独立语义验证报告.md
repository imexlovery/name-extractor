# 33种模板独立语义验证报告

2026年10月12日。当前规则保持0.5.1/r56，本轮没有确认新的真实错误，没有新增生产规则、例外或合成题。

## 验证范围与选样依据

冻结的缺参考池为22,810个标题、27,042条原行，均为33种直接结构模板。槽位长度二字7,021、三字15,789；标点、空格、拉丁字母、扩展区汉字和四字槽位均为0。这个范围不能代表已标注的复杂机构、外文或多人标题。

稀有阈值取每模板不超过12个标题，共19种、76个标题，全部纳入。其余14种模板各抽取ceil(log2(n+1))个固定种子随机标题，另覆盖该模板存在的每种长度、首尾语法字和低频字形态。选择种子为2026101202，没有预设全局样本总数。

边界关注字为“等、人、位、名、同、志、董、理、事、高、管、任、资、格、批、复、核、准、意、和、及、与”。这是采样提示，不是姓名词表。出现“等人位名和及与”的17个标题全部纳入；槽位内完整语法词若出现也全部纳入，本池未出现。低频字定义为在缺参考池至多2个不同标题中出现；每个有该信号的非稀有模板纳入至少1个代表，不宣称覆盖所有低频字。

各模板累计918个标题含低频字。频率最高的两种模板分别有16,085和4,750个标题；最终分别选43和28个。抽样理由重叠，去重后共285标题、308原行。完整槽位来自独立结构审查，仅作统计与选样特征，没有提供给标注通道。

两个无历史上下文的子Agent分别只接收记录标识、完整原标题和共同业务口径，沿用父模型配置。没有读取生产代码、脚本输出、旧参考、正文或彼此答案。285条每路逐标题独立语义判断，代码只序列化显式答案并校核漏行。实际工具过程限制和模型配置边界记在blind-manifest.json；不宣称采用两个不同模型或历史gpt-6.1-sol/medium配置。

共570份首答，A/B一致285，全部与冻结r56输出匹配；参考分歧0、无效0、确定差异0、未决0。没有首答更正，没有发现真实漏人、多提称谓或人数误判。各通道每个标题均给出简短原文边界理由，首答保存在../labels/template-semantic-a-01.jsonl与template-semantic-b-01.jsonl。
