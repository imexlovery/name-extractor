## 从哪里开始复核

[候选复核索引](r64-候选复核索引.csv)把原标题、全部原表行号、生产单元格、脚本候选、旧人工记录和收尾AI首答放在同一行，最后一列可记录人工意见。它包含179个不重复标题、189条原行，供定位和复用证据；不是新增的179条必填表，也不是随机准确率样本。

| 范围 | 标题与原行 | 本次需要处理什么 |
| --- | --- | --- |
| 最后生产变化 | 18200、44338两标题两行 | 核查原标题确无明示姓名，本轮只把字数空白变为数值0；旧无姓名判断已有记录，但尚无本轮变化后的人工确认 |
| 新旧判断分歧 | 39226，一行，已含在72未决内 | 旧人工为舒振国，新上下文首答为行舒振国。核查机构后“行”的归属，记录标题依据和是否借助正文；不能靠多数票或熟悉度删字 |
| 已知漏提 | 11008，一行，已含在72未决内 | 旧人工已确认为白玉娥、李毅昕，无需重填姓名。须有通用脚本修正及回归证据，才能关闭已知错误 |
| 全部脚本未决 | 72标题79行 | 先复用既有判断和逐题依据；其中旧确定人工答案待完成64标题67行，41条候选相同但仍弃权、23条候选不同，不能全称为已确认错误 |
| 当前保留输出的人数风险 | 105标题108行，与72未决不重叠 | 按具体结构选择针对性人工检查，出现分歧再扩查同族。四字长度只是风险，既有AI一致没有证明内部人数 |

最先需要的新增人工输入是第18200、44338两条最后变化确认，以及第39226行的分歧核查。第11008行是工程修正事项，不能通过再次确认同一答案消除。原122条人工记录继续复用，不要求重填原694加200共894条集合。

这三个优先人工检查不等于已建立超过99.8%的全量准确率证据。最终人工范围还须结合未修正错误、72未决、105人数风险及既有参考的代表性决定；不能在三个检查完成后自动宣布验收通过。
