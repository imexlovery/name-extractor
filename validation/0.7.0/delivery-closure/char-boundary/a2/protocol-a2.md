# 字符语境实验 A2：事前协议

2026-10-13。A1 的 430 个结构样本、原 fit/calibration/holdout 分组、唯一模型和校准规则保持原样。A1 校准结果 `selected=null`，因此 A1 的 holdout90 与所有目标题均未评分；该失败记录继续有效。A2 明确修订材料与一元特征来源：补回最初提案中约 22,527 条来自原始标题的裸二至四字短主体，作为弱字符位置和内部语境材料。它们不是人工确认的单人姓名，不是校准标签，也不把 A1 的失败改写成通过。

## 数据来源与隔离

- 只读 `.local/pilot-20261010/inventory.jsonl` 的 `row`、`rows`、`title`。不导入或调用生产提取器，不读取脚本提取值、人工答案、AI答案或其他答案字段。
- 每条候选标题独立按完整语法解析：`关于` + 可选动作前缀（`同意核准|不予核准|核准|批准|同意|核定|确认|注销`）+ 2–4 个纯汉字 + 可选连接字 `的` + `任职资格的批复`。解析时先匹配最短的 2–4 字主体并将紧接主体的连接字消费为语法连接词，例如“关于张三的任职资格的批复”主体为“张三”；不接受语法外文字、空白、标点或未消费残词。
- 逐项沿用 A1 的 `NON_PERSON` 拒收识别，拒绝机构、岗位、职责、残余介词和连接词等命中项；解析通过也不把主体视为真姓名。
- 目标隔离只用 A1 `target_exclusions` 产物中的目标完整标题/重复原行和目标候选连续子串集合。主体命中任何候选的长度至少 2 的连续子串即排除。目标字段只用于排除，不传入拟合、校准或解码。弱主体若与 A1 任一 calibration/holdout 样本的 `parts` 或 `text` 相同，也排除。对每条原始候选保存来源与全部适用排除原因；目标题内容不复制进 A2 的弱来源记录。
- 所有合格弱主体只进入拟合。A1 的 430 个结构样本及 `groups.json` 中的 group/split 原样沿用。弱主体不分入校准或留出，也不更改 A1 约 60/20/20 分组。全部拟合主体与 A1 fit 的 `parts` 去重合并，重复标题不会增加权重。每个不同 A1 fit 原标点名单表达只计一次。

## 固定模型

- 沿用 A1 单一加一平滑朴素特征模型、动态规划解码、每段最少 2 字、无最大长度、无姓氏表和无完整姓名查询。
- 起止位置一元计数来自去重后的拟合片段：左边界计片段末字，左内部计所有非末字；右边界计片段首字，右内部计所有非首字。片段内连续二字、三字上下文按内部计数，重复片段不重复计数。
- 边界跨隙二字、左三字、右三字特征只来自 A1 fit 中原始标点明确的名单边界；同一唯一名单表达只计一次。A1 fit 的其他结构不产生边界跨隙 n-gram。
- 所有已观察特征权重为 1、加一平滑。未见二/三字特征不贡献分数；未见左/右单字角色使候选覆盖不足。所选切分仍要求每个切口左侧字符曾在拟合片段结尾出现、右侧字符曾在拟合片段开头出现。
- 保留 A1 原 `decode` 与 `calibrate` 搜索和评价优先级：偏置取校准间隙分数的相邻中点、两端外一点及 0；每个偏置的 margin 是错误完整预测最大竞争差，可靠输出须竞争差严格大于 margin 且大于 0。先要求校准可靠完整预测零错误，再最大化多人名单恢复与至少 5 字整体保护覆盖率的较小者，再最大化可靠正确标题数，最后以偏置绝对值更小（及 A1 的原次序）破同分。校准须同时有至少一条可靠正确名单恢复和一条可靠正确长整体保护，否则 `selected=null` 并停止。

## 冻结、留出与停止

只执行一次 A2 拟合和校准搜索。先将聚合模型、来源/排除、计数、校准搜索结果与 `frozen-parameters.json` 写入 `a2/`。只有冻结参数 `selected` 非空时，才第一次并且仅一次评分此前未使用的 A1 holdout90。任一可靠留出错误、长整体无可靠覆盖或名单无可靠覆盖都按原协议停止；不再修改算法、放宽弃权、移动材料或调整阈值。`selected=null` 时不运行留出。

不得为 39 个目标、11008、额外四字风险题或其他目标题计算预测、解码结果或错误标签，也不得据其调参。目标子串仅用于事先规定的防泄漏排除。A2 的结构题结果是结构代理表现，裸主体是弱监督字符材料；两者都不构成真实原表准确率或人工验收。A2 与 A1 分开报告，A1 失败状态完整保留。A2 独立脚本为 `experiment_a2.py`；完成后只汇报来源与排除、冻结校准数值，以及若已获准运行的 holdout90 数值。进入目标 B 需要主 Agent 另行批准。
