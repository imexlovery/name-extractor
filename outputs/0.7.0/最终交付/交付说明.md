## 本地复现

在项目根目录运行：

```sh
uv run python -B -m unittest discover -s tests
uv run python -B scripts/full.py run
uv run python -B scripts/acceptance.py final_compare
uv run python -B scripts/human_confirmation.py serve
```

服务器打印100条确认表地址，用户阅读后勾选，自动保存；错误或无法判断填写理由。人审后重新运行final_compare更新真实计数，报告不得在检查前记为100条完成。
